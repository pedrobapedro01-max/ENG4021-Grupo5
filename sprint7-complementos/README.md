# Telas complementares — Sprint 7

Três protótipos independentes em HTML e CSS, sem JavaScript ou backend:

- `termos-de-uso.html` — texto provisório sujeito à revisão da equipe.
- `historico-treinos.html` — registros fictícios para demonstração.
- `notificacoes.html` — avisos estáticos de exemplo.

Abra qualquer arquivo HTML no navegador. O CSS compartilhado está em `estilos.css`.

**Pendente:** alinhar identidade visual ao Figma, integrar rotas/dados com a aplicação principal e validar os termos de uso antes de publicar.
